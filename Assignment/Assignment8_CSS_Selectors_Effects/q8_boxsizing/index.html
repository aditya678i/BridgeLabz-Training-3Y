box-sizing: content-box vs border-box

content-box (default)

width: 250px, padding: 20px, border: 5px

Total rendered width = 250 + 40 + 10 = 300px

box-sizing: border-box

width: 250px, padding: 20px, border: 5px

Total rendered width stays exactly 250px

With the default content-box, padding and border are added on top of the specified width, so the box grows larger than 250px. With border-box, padding and border are included inside the specified width, keeping both boxes predictable when building layouts.
