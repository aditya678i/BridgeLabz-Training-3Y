Responsive CSS Cheat Sheet

Filters

Visual effects like blur, grayscale, and brightness applied directly to an element with the filter property.

Media Queries

Conditional CSS rules that apply only within a given viewport range, e.g. @media (max-width: 700px).

Responsive Design

An approach where layout, spacing, and type adjust automatically across screen sizes rather than using one fixed layout.

Typography

Fluid text sizing using relative units (rem, vw) or clamp() so text scales smoothly instead of jumping at breakpoints.

Flexbox

A one-dimensional layout model, ideal for aligning items in a row or column that need to grow or shrink.

Grid

A two-dimensional layout model for arranging items into rows and columns at the same time.
