What Is Responsive Design?

Responsive design lets a single webpage rearrange itself to stay usable on phones, tablets, and desktops — using flexible layouts, relative units, and media queries instead of one fixed layout.

Cheat Sheet Preview

  • Flexbox — one-dimensional alignment
  • Grid — two-dimensional layout
  • Media queries — conditional styles
  • clamp() — fluid typography
