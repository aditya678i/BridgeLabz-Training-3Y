Core Principles

Fluid Layouts

Widths defined in relative units so containers grow and shrink with the viewport instead of breaking at a fixed size.

width: 100%; max-width: 960px;

Flexible Media

Images and other embedded media scale to fit their container rather than overflowing it.

img { max-width: 100%; height: auto; }

Breakpoints

Specific viewport widths where the layout is adjusted to better fit the available space.

@media (max-width: 700px) { ... }
